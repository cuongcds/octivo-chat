Octivo Chat Widget — Test Page

A simple test page to preview the chat widget embed code and its usage patterns

Sample page content

This page simulates a generic website used to test the chat widget once it is embedded. Set ?channel=@your-source-id in the URL to point every usecase below at a real channel, ?host=https://your-instance.example.com to target a non-default Octivo instance, and ?usecase=n to load a specific one directly (defaults to usecase 1 if missing or invalid).

Base embed code

Drop this single line before </body> to auto-init the widget with a default floating bubble — no further JS required.

ActiveUsecase 1 — Manual init()

Call OctivoChat.init() yourself (instead of relying on data-channel auto-init) whenever your app is ready — e.g. after your own bootstrap logic runs.

<script src="https://cdn.jsdelivr.net/npm/octivo-chat@0.1.1/dist/octivo-chat.min.js"></script>
<script>
  OctivoChat.init({ channel: '@your-source-id', autoOpen: true });
</script>

ActiveUsecase 2 — Pre-fill visitor info (mechanism 2)

If your site already knows the visitor (logged-in user, CRM lead form, ...), pass name/phone directly — the guest-info gate is skipped when both are valid.

<script src="https://cdn.jsdelivr.net/npm/octivo-chat@0.1.1/dist/octivo-chat.min.js"></script>
<script>
  OctivoChat.init({
    channel: '@your-source-id',
    name: 'Nguyễn Văn A',
    phone: '0901234567',
    autoOpen: true,
  });
</script>

ActiveUsecase 3 — Hide bubble, trigger from your own button

Set showBubble: false so no floating button ever renders — call OctivoChat.open() from any element on your page instead (a nav link, a "Contact us" button, ...). The demo below runs both steps at once: it inits with no bubble, then opens the popup from a separate button.

<script src="https://cdn.jsdelivr.net/npm/octivo-chat@0.1.1/dist/octivo-chat.min.js"></script>
<script>
  OctivoChat.init({ channel: '@your-source-id', showBubble: false });

  document.querySelector('#my-chat-button').addEventListener('click', function () {
    OctivoChat.open();
  });
</script>

<button id="my-chat-button" type="button">Contact us</button>

<!-- Or, without any manual init() call — auto-init straight from the tag: -->
<script src="https://cdn.jsdelivr.net/npm/octivo-chat@0.1.1/dist/octivo-chat.min.js"
  data-channel="@your-source-id" data-show-bubble="false" async></script>

ActiveUsecase 4 — React when the visitor closes the popup

Pass an onClose callback to run your own logic (analytics event, show a survey, ...) the moment the popup closes.

<script src="https://cdn.jsdelivr.net/npm/octivo-chat@0.1.1/dist/octivo-chat.min.js"></script>
<script>
  OctivoChat.init({
    channel: '@your-source-id',
    autoOpen: true,
    onClose: function () {
      console.log('Visitor closed the chat popup');
    },
  });
</script>

ActiveUsecase 5 — Listen for the close event globally

Prefer a DOM event over a callback (e.g. to wire up multiple independent listeners)? Listen for octivochat:close on window — it fires alongside onClose, whichever (or both) you use.

<script src="https://cdn.jsdelivr.net/npm/octivo-chat@0.1.1/dist/octivo-chat.min.js"></script>
<script>
  window.addEventListener('octivochat:close', function (e) {
    console.log('Chat closed for channel', e.detail.channel);
  });
  OctivoChat.init({ channel: '@your-source-id', autoOpen: true });
</script>

ActiveUsecase 6 — Returning visitor (session reuse)

Once a guest session exists in this browser (localStorage), it's always reused — calling init() again with different name/phone is ignored until the session is cleared, so the same visitor never gets split into two conversations. The demo below runs both steps at once: it starts a session as Jane, then immediately re-inits as John to show the session is reused, not replaced.

<!-- First visit — creates the session -->
<script src="https://cdn.jsdelivr.net/npm/octivo-chat@0.1.1/dist/octivo-chat.min.js"></script>
<script>
  OctivoChat.init({ channel: '@your-source-id', name: 'Jane', phone: '0901111111' });
</script>

<!-- Later, on the same browser — "John" is ignored, Jane's session resumes -->
<script>
  OctivoChat.init({ channel: '@your-source-id', name: 'John', phone: '0902222222' });
</script>
